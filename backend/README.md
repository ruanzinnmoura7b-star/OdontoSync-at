# Backend OdontoSync

Backend em Node.js, Express e SQLite.

## Instalar

```bash
npm install
```

## Rodar Clínica A

```bash
npm run dev:win:a
```

## Rodar Clínica B

```bash
npm run dev:win:b
```

## Bancos

Os bancos são criados automaticamente em:

```txt
src/data/clinica-a.sqlite
src/data/clinica-b.sqlite
```
